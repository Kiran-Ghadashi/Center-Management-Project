# 🎓 Center Management System

## 📌 Project Overview
Center Management System is a web-based application developed using **Python and Django** for managing a computer training center. The system helps administrators handle student admissions, enquiries, fee collection, and reports from a single platform.

This project is suitable for training institutes offering courses such as:
- MS-CIT
- Tally
- Advanced Excel
- Full Stack Development
- Other Computer Courses

---

## 🚀 Features
- Enquiry Management
- Fee Management
- Reports and Dashboard
- Student Admission Management

- User Authentication and Login
- Student Record Management
- Responsive Web Interface
- Database-driven Application

## ⚙️ Installation

### 1. Clone Repository
```bash
git clone https://github.com/Kiran-Ghadashi/Center-Management-Project.git
```

### 2. Move to Project Directory
```bash
cd center-management-system
```

### 3. Create Virtual Environment
```bash
python -m venv venv
```

### 4. Activate Virtual Environment

**Windows**
```bash
venv\Scripts\activate
```

**Mac/Linux**
```bash
source venv/bin/activate
```

### 5. Install Dependencies
```bash
pip install -r requirements.txt
```

### 6. Apply Migrations
```bash
python manage.py migrate
```

### 7. Run Server
```bash
python manage.py runserver
```

### 8. Open in Browser
```text
http://127.0.0.1:8000/
```
